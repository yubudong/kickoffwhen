# 多页作业批改与订正

确认范围：20页图片、连续拍照/选图、排序旋转删除、独立上传进度与失败重试；保留原图、独立圈线箭头编号文字批注；家长自动保存草稿、发布退回；孩子跨天待订正、原页关联补拍；不可变提交与审核历史、前后对照；最终通过仅发奖一次，兼容原单附件/音视频/听写。

## 数据与事务

- 新图片逐张预上传到既有私有todo媒体目录，新上传登记表绑定家庭/孩子/任务/幂等命令及SHA-256；校验真实图片格式、像素上限、文件大小，压缩和去元数据，原始上传画面保留在规范化图像中，不写批注覆盖照片。
- 正式提交仅引用已授权上传或同任务的既有提交页。最多20页，明确顺序、0/90/180/270方向、稳定pageKey及parentPageKey（订正关联原页）。不接受任意外链/文件ID/MIME。
- 旧todo_submissions、todo_reviews、todo_rewards保留；新增提交详情、页明细、审核草稿和发布快照。旧单附件在历史视图投影为第1页，不迁移/删除旧媒体；本轮新图片优先兼容旧attachment预览字段，保留旧字段唯一约束，全量页明细由新视图读取。
- 提交/发布使用任务当前submissionNumber+updatedAt和命令指纹，按原wallet→task顺序加锁；失败回滚元数据，幂等重试不重复提交或发奖。图片上传先成功并不等于任务已提交。
- 复用原submit/review的听写完成、周次数、奖励审批及唯一todo奖励约束，不重算历史积分。
- 草稿仅家长可见，独立revision防并发覆盖；发布时冻结每页批注/要求。旧审核入口若存在未发布批注草稿，提示转工作区，避免误丢批注。

## 交互

- 任务抽屉提供开始批改/查看订正链接；独立大图工作区按角色投影历史与草稿。
- 上传失败逐张重试，预览可旋转/调整顺序/删除，提交前确认页数。订正默认保留既有页面，新照片可关联原第几页；删除仅影响本次提交组合，旧历史仍保留。
- 以归一化坐标保存SVG笔迹，缩放/旋转/手机屏幕不改变批注位置。原图/批注切换、撤销/删除/页级要求、整体反馈。
- 发布退回必须有明确文字要求。子页面突出家长反馈和标记；单独跨日期待订正列表，不把历史任务挪到今天或复制发奖。
- 每轮提交、发布批改和最终通过组成时间线，可按原页对照订正图片；家长草稿不会泄露给孩子。

## 验证

跨家庭/孩子上传及附件读取、草稿隐藏、原页关联归属、20页/大小/真实图片约束、重复上传/提交/发布、旧页面冲突、反复退回后只发一次奖、旧单附件和录音听写回归、旋转缩放标注坐标、手机多图和跨天提醒。生产先备份恢复迁移，核对原53表旧列/记录/媒体保持。
