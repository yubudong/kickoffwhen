## 如何理解版本

平台“2022课标修订资源”与“平台原版资源”按册区分，资料整理时间不是教材出版时间。年级、上下册、出版社、系列都参与身份判断。资料库和下发页新增“教材版本”筛选，教材展开后才渲染单元/词条，避免两万多条内容一起生成大量页面节点。

一年级起点和三年级起点不可仅凭出版社名称互换。此轮不能声称截图中所有旧版/低年级教材全套完成，详见[覆盖边界](../content/english-multi/coverage-notes.json)：人教新起点旧版、一至二年级、部分旧一年级起点、牛津实验本、新蕾快乐英语等仍需能核对同版目录与词表的来源。页面只展示已经导入的实际教材，不增加没有词条的版本选项。

湘少三年级下册的一页来自同书另一个公开条目，其相邻两页SHA-256与选中条目完全一致，保留补充页实际URL。鲁科五四制三年级下册较新条目缺页、另一条目版式不同，改选完整的2024平台条目并单独标识，没有跨版本拼页。

## 词表与听写要求

“出现在教材词表”不等于“每个词都要求四会”。未逐词可靠恢复黑/白字体教学分层的资料统一标为“教材词表·自选听写”，不冒称教材必写词。PEP既有明确读写/核心/认读分层、默认范围和999条元数据不变。

按原词表提取词和短语，句型、省略模板、故事题名及版式标记不当作词条；括注中的过去式/复数信息不拆成错误单词。双栏、单栏、带单元编号的字母索引分别核对，OCR页码、星号、音标和水印不混入目标拼写。

中文辅助释义经来源与词义核对，少量缺失释义由编辑补充；辨音语境是自编练习提示，不冒充教材原句。没有核实例句时不展示占位例句。缩写与多音词按词形/词义处理；标准听写不显示答案/音标/中文，辅助模式只投影允许的提示，完整资料在批改阶段展示。

## 校验与保持

- 每条卡片绑定来源页与元数据摘要，整册身份、单元顺序、稳定标识和总数校验。
- 同词跨版本保留独立归属；重复导入不重复建卡；仅新增资料可用`pnpm seed:content --apply --extended-english-only`单独导入。
- 323项单元、209项集成、36项Chrome/WebKit浏览器和5项备份安全测试通过；类型/lint/生产构建通过。旧PEP/中文功能回归通过，保留8条既有媒体追踪构建警告。
- 全库测试库实际包含全部新资料，验证版本筛选、原页链接、懒展开、手机390px、键盘操作、按课下发、标准/辅助与孩子隔离。
- 正式导入前做一致性备份与隔离恢复/导入演练，按原记录ID核对原有内容和学习事实；具体生产结果见[正式发布记录](runbooks/english-multi-deployment-20261125.md)。
