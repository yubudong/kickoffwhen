## 使用步骤
家长：今日待办清单→选择孩子与日期→填写任务和要求→添加。
孩子：完成任务→可选资料→完成并提交→显示待审核。
家长：查看资料→填写奖励积分（默认 0）和意见→通过发分，或填写退回原因。
孩子：自动看到审核通过及积分，或按退回意见完成后重新提交。
听写：今日听写→听写内容库录入→布置听写→自动进入孩子今日待办。
