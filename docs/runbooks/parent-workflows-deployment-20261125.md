## 使用入口

1. 家长概览`/parent`：任务待审核、听写照片待批、兑换待批准和奖励待兑现。普通任务可直接通过/退回，奖励可批准、拒绝、兑现或取消退款，复用原审核和账本服务，不另发一份奖励。
2. 家庭奖励`/parent/rewards`：上半部是全家共享设置，不带孩子选择；下半部按孩子查看个人余额与记录。成长页原奖励页明确标出共享目录并链接到公共设置。
3. 重复习惯`/parent/growth`：点“编辑后续安排”，默认次日起生效；未来开始的习惯从开始日期生效。显示当前规则和已安排的新规则，旧编辑草稿遇到版本变化会拒绝覆盖。已生成、延期、提交和发奖记录不改写，本周计数不因编辑清零。
4. 页底可添加到主屏幕、手动检查更新。更新前提示先保存；断网隐藏页面、暂停听写，恢复后由孩子手动继续，不自动提交或发奖。

## PWA与移动验证边界

Service Worker只缓存通用离线页与图标，不缓存API、登录/家庭页面、孩子资料、听写答案、照片和音频，也不排队写操作。导航强制网络no-store/include，避免身份切换复用旧跳转；断网后即使WebKit保留旧文档，隐私遮罩也隐藏原内容并暂停听写，在线恢复后保留原草稿与手动继续。

含网络故障注入的旧套件按Playwright建议禁用Service Worker以确保模拟有效；PWA和真实双孩子套件保持Worker启用并检查实际CacheStorage与离线页面。并未声称已替用户在真实手机完成安装或连续使用一周，家庭实际试用仍需用户执行。
