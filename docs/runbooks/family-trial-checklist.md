# 家庭连续试用清单（待实际使用）

工程回归和部署验收已完成；这张表用于接下来真实家庭使用，不代表孩子已经试用过一周。先每位孩子设置1–2条习惯，奖励量先保持稳定，再根据实际记录调整。

## 第一天

- [ ] 用真实手机/平板添加主屏幕，分别进入两个孩子；家长模式仍需原PIN。
- [ ] 家庭奖励页添加1–2份全家共用奖励，切换个人记录筛选不会改变公共清单。
- [ ] 两个孩子各完成一次任务，确认只有对应孩子收到星币和待投喂成长值。
- [ ] 家长概览看到待审核项目，核对后通过；原听写照片批改和待办奖励审核仍分开。
- [ ] 选蛋时预览动物/男性/女性形态，理解人形少年期解锁；投喂后由孩子主动开启成长。

## 第2–3天

- [ ] 编辑一个习惯，确认页面显示生效日期；当天已生成/延期任务保留原名称与奖励。
- [ ] 新的一天按新规则生成，不重复已有任务，本周次数不因编辑重置。
- [ ] 申请一份现实奖励，核对冻结、批准扣款、实际兑现完成；取消或拒绝后正确退回。
- [ ] 短暂断网，确认内容遮罩和听写暂停；恢复后手动继续，避免刷新尚未保存的批改。
- [ ] 切换孩子后不出现另一位的答案、照片、余额或待办；主屏幕入口能恢复原授权流程。

## 第4–7天

- [ ] 每天家长只花几分钟处理概览，记录仍需来回切页的地方。
- [ ] 记录每天完成任务数、待投喂/累计吸收成长值和星币，观察商品是否容易理解、买得起。
- [ ] 区分“已经赚到但尚未投喂”和“伙伴已吸收”；不因一天没完成扣已有成果。
- [ ] 观察初生/幼年成长是否有期待感，不急于用额外奖励跳过阶段。一天约50基础成长时，少年约18天、成年约36天，一周不应承诺自然解锁全部形态。
- [ ] 核对服务器每日备份、Mac最近同步与恢复验证状态。Mac离线期间只保证服务器本地备份按任务执行，异机副本等在线后补拉。

问题记录建议：时间、使用设备/浏览器、哪位孩子（本地昵称即可）、所在页面、具体操作、期望与实际；截图留本地，不必公开孩子个人资料。先修复可重复的问题，再调整奖励节奏或增加新玩法。
