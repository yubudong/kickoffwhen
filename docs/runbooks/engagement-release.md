## 使用入口

- 家长：导航“习惯与成长”（`/parent/growth`），选择孩子，在“重复习惯”创建每日、指定星期或每周N次习惯；最多5个活跃习惯，可编辑后续安排，默认次日起生效，已有任务和历史奖励不改写。
- 家长：原“待办清单”支持设置一次任务的星币、成长值及确认方式。在任务详情使用“今天跳过”“延到明天”。重复习惯可从成长页停止后续安排。
- 孩子：今日待办进入“我的伙伴 · 星币与奖励”（`/child/companion`）。免费选择青龙、月灵狐、星羽凤凰、森屿水豚、绒云兔、墨星猫、霜岚狼、虹光独角兽、赤焰灵猿或曜石玄龟的蛋，完成任务后投喂待投喂成长值。
- 孵化和每次进化必须主动点击，投喂不会跨越下一门槛；已经解锁的变化可在成长相册重看。月灵狐、星羽、墨星猫、霜岚狼在少年和成年期可选择动物或男女人形，另四种保持动物／神兽形态；赤焰灵猿和曜石玄龟为男性化形路线。选蛋预览、实际伙伴和相册都直接显示动物/男性/女性选项，不再通过隐藏的男女切换按钮寻找男性。可以切回已解锁的年龄外观，不改变真实成长进度。
- 星币商店中永久装饰只购买一次，食物提供互动；三种7天祝福各＋10%，同种续时，不同种最高合计30%。购买不立即计时，在背包主动激活。
- 家长概览集中审核任务、听写和兑换；家庭奖励在独立公共页面设置，全家共用，孩子筛选只影响个人余额与申请记录。家庭奖励由家长定价；孩子申请冻结星币，家长批准扣款，实际兑现后标记完成。拒绝、取消会退款；已批准申请仅家长能取消。
- 家长可在“成长记录”手动调整星币或补发成长值，原因必填；不能扣掉已冻结星币，也不减少宠物累计成长。

## 奖励与时间规则

- 历史积分1:1转为星币，保留原todo_rewards及每条来源，不追溯历史成长值。
- 默认任务1星币、10基础成长值，可设置0–10000。审核额外星币独立记录。听写仍需原待办审核后发奖，不因上传批改照片自动奖励。
- 成长门槛为50初生孵化、300幼年、900少年、1800成年；成年之后继续累计等级。按一天约50成长值，约1天、6天、18天、36天；实际取决于家长设置的奖励量。
- 加成在孩子完成/提交时锁定，审核延迟不影响，退回重交重新计算。向下取整，只加基础成长值，不加星币或已有成长值。
- 家庭时区采用Asia/Shanghai（与当前用户Asia/Singapore均UTC+8）。每周周一至周日，每周N次每天最多一次，待审核占名额，退回释放；不跨周积压。
- 延期只移动本次，与同习惯次日任务合并；跳过不扣已有奖励，后续重复规则不变。网络重试使用版本防护，避免延期请求重复移两天。
- 现实奖励限制按申请周计数，待批准、已批准、已完成占次数，拒绝/取消释放；保存申请时价格快照。价格在确认期间变化时要求刷新。
