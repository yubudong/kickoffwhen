# 家长常用任务模板

家长要求：添加待办时可保存常用任务，下次点选快速下发。范围：名称、要求、星币、成长值与确认方式；家庭共享、编辑、删除、点选填充后确认孩子/日期。不会自动创建重复习惯，也不会批量改已下发任务。

新增家庭级todo_task_templates表，不给旧todo_tasks增加依赖。任务下发仍按原创建服务写入独立字段快照；模板无孩子和日期。软删除模板只移除可选项。

创建/修改/删除命令带幂等commandId与指纹，修改/删除要求revision，家庭行锁保证并发数量上限；每家庭最多200个有效模板。创建重试不重复建模板，过期编辑不覆盖新模板。GET/POST仅解锁家长可访问，家庭身份来自actor，不接收客户端familyId。

添加表单上方提供常用卡片、搜索和模板管理。点选仅填充名称/要求/奖励/确认方式，不替换孩子或日期；保存模板不创建任务。模板编辑在独立对话框中进行，提示不影响已下发任务或当前待办表单。保留日/周/月日期选择、现有手工任务、作业批改、听写、奖励与重复习惯行为。

验证家庭/孩子权限、幂等与修订冲突、字段校验、模板删除/修改不影响已创建任务、切换孩子/日期、手机与Chrome/WebKit完整流程、旧功能回归；正式上线前备份恢复迁移并逐表核对原58表数据与媒体保持。
