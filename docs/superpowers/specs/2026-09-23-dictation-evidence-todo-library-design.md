# 听写资料提交、待办修改与教材内容库设计

日期：2026-09-23。范围：现有家庭学习网站的孩子听写、家长今日待办与听写内容库。Tom 已确认：听写照片可选，沿用现有待办附件和家长审核流程。

## 目标与边界

1. 孩子完成听写和错题订正后，能主动提交任务；提交时可附一张照片，也可不附照片。家长按孩子实际情况审核，不由系统强制要求照片。
2. 家长能修正尚未提交的普通待办，并撤回误添加的普通待办。保留既有审核、附件及积分记录，不做不可恢复的硬删除。
3. 听写内容库以教材为顶层入口，按单元、课次逐级展开；不再默认展示所有词语卡片。自建内容与教材内容分开。

本轮不新增 OCR 判卷、多照片上传、英语教材数据、批量编辑待办或自动审核。既有已提交、已审核的听写任务保持原状态，不倒改历史。

## 当前实现与方案选择

当前听写会话完成时在同一事务中调用 `submitDictationTodo`，自动把关联待办设为 `submitted`；孩子无法先选照片再提交。普通待办已有文件上传、私有媒体、家长审核和积分机制。家长待办清单只有添加与审核，没有普通待办编辑/撤回；内容库把所有卡片铺成列表。

采用复用方案：听写完成只更新会话和学习任务，不自动提交待办；孩子经现有 `/api/child/todos` 提交，可选用现有私有媒体附件。普通待办编辑/撤回沿用 `todo_tasks` 生命周期，内容库复用教材版次、单元、课次元数据。相较于另建一套听写上传/审核系统，此方案避免重复附件、权限与积分规则；相较于直接硬删除待办，软撤回保留审计线索。

## 孩子听写提交流程

- 会话全部听写和订正完成后，学习任务与会话保持现有 `completed` 事实；关联待办继续保持 `open`，直到孩子明确点击“提交家长审核”。这时孩子首页标注“听写已完成，待提交”，不提供重新听写按钮。
- 完成页显示“提交资料”入口与“上传照片（可选）”文件选择；可直接提交，也可选择一张 JPG、PNG 或 WebP 照片后提交。沿用现有 8 MB 上限、真实文件签名校验、私有媒体存储与访问鉴权。听写待办不接受音频或视频附件；普通待办原有附件方式不变。
- 孩子离开完成页后，今日待办清单的同一听写任务仍显示提交入口。若跨日回来，完成页仍能直接提交，不依赖“今日”日期筛选。
- 完成页所需的关联待办 id、日期、提交序号和状态，仅在完成阶段通过孩子权限范围内的会话视图提供；不能泄露听写答案。提交调用现有待办接口，服务端继续验证家庭/孩子归属、会话及学习任务确已完成、待办状态和提交序号。重复点击、过期页面或并发提交只产生一次有效提交；已保存却未能关联的上传文件按现有失败清理机制删除。
- 成功后待办变为 `submitted`，孩子看到“等待家长审核”；家长能在原审核处看到照片并通过或退回。退回后孩子可重新提交，可重新选一张照片或不附照片。已通过的奖励记录不变。
- 旧版已经自动提交的听写维持原有 `submitted`、`approved` 或 `rejected` 及附件记录，完成页只按实际状态展示，不新建提交。

## 家长普通待办编辑与撤回

- 在家长今日待办的普通待办行提供“编辑”和“撤回”。编辑可修改标题、任务要求和日期；不允许改派孩子，选错孩子时应撤回后重建。只允许状态为 `open` 的普通待办编辑，提交后的修改要求使用现有“退回并写审核意见”流程。
- 普通待办在 `open`、`submitted` 或 `rejected` 且没有奖励记录时可撤回。撤回前二次确认；服务端在事务内按家庭锁定待办并复查状态/奖励，把状态标为 `cancelled`。孩子清单不再显示，家长清单保留“已撤回”记录；已有提交资料和审核历史不删除。`approved` 或已有积分的待办拒绝撤回。
- 听写待办仍由现有听写任务撤回入口处理，普通待办接口不得绕过听写会话的撤回与并发保护。编辑/撤回均要求家长身份、同家庭范围和同源请求；已变化页面返回可理解的“状态已更新，请刷新”提示。
- 家长修改日期后，该待办立即归入新日期清单；原日期页面刷新后不再显示。撤回记录不计入孩子未完成任务数。

## 教材内容库导航

- 默认页只显示各教材（科目、年级、上下册、出版社/版本）及各自的单元数量、词语数量；展开教材才显示单元，展开单元才显示课次/语文园地及数量，展开课次才显示该课词语列表。词语仍可展示拼音、语境与来源，但不使用逐张卡片的密集布局。
- 教材树基于已有 `textbook_editions`、`textbook_units`、`textbook_sections` 与 `learning_cards` 关系构建，排序按教材中的版次、单元和课次顺序，不按创建时间打散。自建、批量和 OCR 词条中未归属教材的内容进入独立“我的自建内容”分组，按科目显示数量与条目。
- 没有内容的教材或英语科目显示空状态，不伪造词条。手机窄屏和键盘操作保留可展开结构与清楚的层级、数量、焦点状态；默认不展开所有词语。

## 数据、安全与兼容

- 复用现有待办状态、提交、审核、奖励和私有媒体表；预计无需数据库迁移。需要修改听写完成的事务调用、孩子完成视图、待办服务/API、家长待办界面和内容库查询/页面。
- 服务端而不是仅浏览器决定可编辑、可撤回、可提交及文件类型。所有读取和变更都按家庭/孩子隔离；附件仍经授权路由访问，页面不暴露服务器文件路径。
- 新语义不修改历史记录。部署前需针对现有生产记录验证旧已提交任务仍可查看审核，且新完成任务不自动跳过孩子确认。生产发布及真实账号操作需单独确认。

## 验证标准

- 服务与集成测试覆盖：完成听写但未提交、无照片提交、合法照片提交、拒绝非图片/超限文件、重复提交、退回重提、跨家庭/孩子越权、旧已提交数据不变。
- 待办测试覆盖：编辑 `open`、旧日期转新日期、已提交/已通过不可编辑；撤回各允许状态、已奖励禁止撤回、并发审核/撤回只允许一个结果、听写待办不能走普通撤回接口。
- 内容库测试覆盖教材/单元/课次排序与计数、自建内容归类、空状态。浏览器测试覆盖孩子完成→可选照片→提交→家长查看/审核、家长编辑/撤回及教材逐级展开；再运行 lint、类型检查、单元、集成、双浏览器端到端与构建。
