# 分层布置听写与自动复习设计

日期：2026-09-23。状态：Tom 已确认实施。

## 目标与范围

家长从“五年级语文 → 单元 → 课次／园地”选择听写范围，不必逐张勾选词卡。选择单元一次提交后，每课生成一项孩子任务。家长可另行搜索并添加易错词；可撤销误下发的任务，以及从未开始的任务中移除误加词。孩子清单清楚显示完成、审核及积分状态，听写中可返回清单。已有 FSRS 记忆曲线继续决定词卡到期时间；到期词每天自动汇总成复习任务。

## 布置页面

- 默认只显示孩子、教材树和简短汇总；卡片列表不展开。教材树从现有 textbook editions、units、sections 构建，按教材及来源分组，不能仅由客户端可见卡片推断可下发范围。
- 家长展开五年级语文可看八个单元，展开单元可看课次。父级勾选选中所有尚可下发的小节；半选状态清楚表示只选部分小节。预览展示“将生成 N 项任务、M 个新词”，每课的词数可见。若某课词已在该孩子进行中或已学习过，显示可用词数与不可用原因；不默默重复下发。
- “单独加练易错词”是独立的搜索抽屉，只在打开时展示词语。它能选教材或家长自建的词，当前已在活跃任务中的词不可重复加入；此前已学过的词可主动加练。加练词形成一项独立任务。
- 布置设置沿用连续/逐题、顺序、间隔、次数、语速。到期复习由自动任务承担，手动批量布置不再把同一批到期词塞进每课任务。

## 服务端创建与幂等

- 新增一次提交多个课次的 API。客户端只发送教材小节 ID 和加练词 ID，服务端按家庭、孩子、科目、教材关系解析真实卡片；权限不依赖客户端提供的词数或标题。每课及加练各生成一项 learning task 与相应 todo。
- 整组任务在同一数据库事务创建；命令 ID 与输入指纹保证网络重试返回同一批结果。若某课无可用词，预览显示并跳过；全组无可用词时报清楚错误。每个任务的展示标题、科目、单元、小节、来源保存在任务记录或其关联 todo 上，使孩子和家长均能看到明确名称。
- 每项任务最多 100 词；当前词库每课小于此限。既有单任务 API 继续可用，不破坏旧任务。

## 自动复习

- 既有 FSRS 状态继续在首次答题及同次订正时更新。错误词在本次任务内完成订正；以后仍按 FSRS 的 `dueAt` 进入下一轮。自动复习不用固定“第二次、第三次”间隔，也不预先复制词卡。
- 每天北京时间 06:00 后，Worker 为每位有到期词的孩子、每个科目最多创建一项“到期复习”任务，最多 20 词。重启后补跑当天，多个 Worker 或重试不重复生成；已在活跃任务的词跳过。超出 20 词的积压留待下一天。
- 音频沿用现有 TTS 队列及缓存。未准备好时任务显示“音频准备中”，不能误报为可播放。若当天已创建自动复习任务，后来到期的词留到下一天；这避免短期学习步长触发一天内多项任务。

## 撤回与记录

- 提交前可取消单元／课次／加练词。家长在已创建任务的详情中可移除尚未开始的任务词；移除最后一词等于撤回整项任务。任务一旦开始，词条构成锁定，避免学习历史与题号错位。
- 家长可撤回未审核通过的整项任务，包括进行中的误派任务；进行中页面收到撤回状态后返回任务清单。使用软取消并保留已有播放、作答、审核历史。审核通过且积分已到账的任务不允许撤回，以免暗中改变积分账目；家长界面给出原因。
- 撤回的任务不计入孩子待完成数，家长历史可查“已撤回”。相关 todo 与 learning task 在同一事务变更。既有家庭历史、词卡记忆状态、媒体及积分不会因撤回而硬删除。

## 孩子端

- 今日清单以每课任务名呈现，顶部显示“待完成 N / 已完成 N”。单项状态区分准备中、进行中、待家长审核、审核通过且积分到账、审核未通过。累计积分沿用现有奖励记录。
- 听写页始终有“返回今日清单”。返回前等待正在提交的命令；若批改选择尚未提交，提示这些临时选择不会保留，已保存的听写进度仍可恢复。完成后返回清单，不让孩子陷在单项页面。
- `/child/tasks` 与 `/child` 指向同一组任务状态和名称，避免一个页面只显示活跃任务、另一个页面显示审核结果造成混淆。

## 数据与发布

- 新迁移接在正式 `0020` 后，以增量方式记录任务来源及批量命令所需身份，扩展 todo 撤回状态。所有旧任务、todo、审核、积分、FSRS 状态照旧可读。
- 先在独立数据库核对 0020→新迁移、旧记录不变，再测批量事务与重试、越权、自动复习去重、撤回、孩子状态和导航。浏览器验证折叠树及完整孩子流程。
- 生产切换前备份数据库与媒体；只切换 Web/Worker，旧镜像保留。发布后对比家庭数据计数与健康状态；真实 TTS、审核积分和移动设备导航需小范围实际验收。

## 不做的事

- 不改 FSRS 参数，不把所有错误词当天无限追加为新任务，不删除已取得积分的学习记录。
- 英语词库仍需实际教材；树形结构支持以后填入英语单元，不编造词条。
