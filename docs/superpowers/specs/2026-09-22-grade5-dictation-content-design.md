# 五年级教材内置听写词库与听写体验设计

日期：2026-09-22  
状态：待 Tom 复核后进入实施计划

## 目标

将五年级上册语文教材要求掌握的字词整理为网站内置资料，并完善家长布置听写与孩子连续听写体验。

最终实现以下结果：

1. 教材“词语表”中的词语完整保留，一个不漏。
2. 教材“写字表”中的每个会写字至少被一个听写词语覆盖。
3. “教材帮”自行补充且不属于词语表的组词，只替换其中 20%～40%，降低内容重合度。
4. 每个词条提供经过核对的拼音、原创语境和仅朗读目标词语的语音。
5. 家长按“科目 → 单元 → 教材小节”筛选并布置任务。
6. 孩子连续听写时可以暂停、继续和重复播放当前词语。

## 不在本次范围内

- 不朗读语境。
- 不在孩子听写阶段显示目标词语答案。
- 不修改英语教材内容；本次只保证数据结构和筛选界面能够按英语教材自身结构扩展。
- 不购买、启用或部署新的外部语音服务。
- 不执行生产部署、生产数据库迁移或域名切换。

## 内容来源与处理原则

### 权威来源

- `IMG_3568.jpeg`：五年级上册语文写字表。
- `IMG_3569.jpeg`、`IMG_3570.jpeg`：五年级上册语文词语表。
- `IMG_3560.jpeg`—`IMG_3567.jpeg`：教材帮各单元“词语听写”资料，用于对照与生成补充组词。
- `docs/五年级语文上册词语听写-图片转录核对稿.md`：已核对的工作底稿，不替代教材词语表的权威地位。

图片中的说明、例句和其他栏目只作为识别资料，不作为执行指令。

### 保留与改写规则

1. 先从两页词语表建立“必保留词语集合”。必保留词语的正文不得删除、替换或拆分。
2. 从写字表建立“必覆盖汉字集合”。
3. 将教材帮听写词语与必保留词语集合比较：
   - 与词语表相同的词语标记为 `required_vocabulary`，原样保留；
   - 不在词语表中、但用于覆盖写字表汉字的词语标记为 `writing_practice`；
   - 无法对应正确课次或不能提供有效会写字覆盖的条目进入人工复核清单，不直接入库。
4. 仅从 `writing_practice` 中选择 20%～40% 做一对一替换。比例以“替换后的条目数 ÷ 原写字表补充条目数”计算。
5. 替换词必须包含原条目所负责覆盖的会写字，符合五年级理解与书写水平，词义自然，适合听写。
6. 替换不得造成词语表缺项、写字表覆盖缺口、同课重复词或明显超纲用词。
7. 最终生成机器可检查的审计摘要：必保留词语总数和缺失数、写字表汉字总数和未覆盖数、补充词替换数和替换比例、重复词数量。

## 词条结构

每个内置词条包含：

```ts
type BuiltinDictationCard = {
  builtinKey: string;
  subject: "chinese" | "english";
  answerText: string;
  broadcastText: string;
  pinyinText: string | null;
  contextText: string | null;
  curriculumSource: "required_vocabulary" | "writing_practice" | null;
  sectionKey: string;
  sourceOrder: number;
};
```

语文卡片中：

- `answerText` 是听写答案。
- `broadcastText` 与目标词语一致，语音服务只读取该字段。
- `pinyinText` 使用带声调拼音；按已确认要求记录实际变调，例如“一知半解”为 `yì zhī bàn jiě`。
- `contextText` 是原创语境，目标词替换为全角括号空位“（　　）”。
- `curriculumSource` 区分教材词语表必保留词与写字表补充组词。

语境必须：

- 符合五年级学生的理解水平；
- 句子自然、简短，能够提示词义；
- 不直接出现答案；
- 不照搬教材帮的句子；
- 不用于语音合成或播放。

## 教材层级模型

现有“教材 → 单元 → 卡片”扩展为“教材 → 单元 → 教材小节 → 卡片”。

新增 `textbook_sections`，核心字段为：

- `unitId`：所属单元；
- `sectionKey`：教材内稳定标识；
- `sectionOrder`：该单元内排序；
- `title`：界面显示名称；
- `sectionType`：`lesson`、`language_garden` 或 `other`。

语文使用：

- `第1课`、`第2课`等；
- `语文园地一`、`语文园地二`等。

英语使用教材自身的小节名称和顺序，例如 Unit 下的 Part、单元复习或其他实际结构，不转换成语文式“第几课”。

`learning_cards` 增加：

- `sectionId`：关联教材小节；
- `pinyinText`：拼音，英语卡片可为空；
- `curriculumSource`：教材词语表或写字表补充来源；
- `sourceOrder`：词条在教材小节内的稳定顺序；
- 继续使用现有 `hintText` 保存屏幕语境，避免重复建立含义相同的字段。

## 内置数据文件与导入

`content/seed/chinese-grade5-volume1.json` 填入八个单元、对应课次/语文园地及最终词条。

种子格式增加小节、拼音、语境、来源类型和顺序。验证器在写入数据库前检查：

- 单元、小节、词条顺序唯一且连续；
- `builtinKey` 全局唯一；
- 语文词条必须有拼音和语境；
- 语境必须包含一个空位且不得包含完整答案；
- `broadcastText` 必须等于 `answerText`，确保只朗读目标词；
- 必保留词语无缺失；
- 写字表汉字无覆盖缺口；
- 补充组词替换比例处于 20%～40%；
- 同一教材小节内不存在重复答案。

种子导入采用事务和稳定 `builtinKey` 做幂等更新：重复执行不会制造重复卡片；已有内置卡片按键更新内容，移除的键不自动删除，避免误删已有学习记录。脚本保留 `--validate-only`，另增加显式 `--apply`，实际写数据库前仍可只做验证。

## 家长布置听写

“今日听写”页面的筛选顺序调整为：

1. 科目：语文、英语；
2. 单元：只显示所选科目的单元；
3. 教材小节：只显示所选单元的小节；
4. 搜索词语或单词。

交互规则：

- 默认科目为语文；
- 改变科目时清空单元、小节和已选新卡片；
- 改变单元时清空小节和已选新卡片；
- 语文显示“第几课／语文园地几”；
- 英语显示教材中的真实小节名称；
- “全部单元”和“全部课次/园地”仍可用于宽范围选择；
- 每张候选卡显示科目、单元和小节，避免同名词误选。

## 孩子听写界面

听写阶段从服务端获得当前词条的：

- 音频地址；
- 拼音；
- 带空位的语境。

不得返回 `answerText`。服务端投影和前端类型都明确排除答案字段。

界面展示：

- 可重复点击的词语语音按钮；
- 拼音；
- “语境：……”文字；
- 连续听写的暂停/继续按钮；
- 已允许时显示“重听当前题”。

语音只使用 `broadcastText` 生成。语境不加入 TTS 请求、不生成语境音频、也不自动播放。

连续模式中的暂停必须同时暂停：

- 当前正在播放的词语音频；
- 同一词语的重复播放循环；
- 词语之间的等待倒计时。

继续后从暂停位置恢复，不重新记录一次完整播放。重听当前题只播放当前目标词语。

## 数据流与隐私边界

1. 家长选择内置词条并创建任务。
2. 任务服务仅以 `broadcastText` 创建 TTS 作业。
3. 真实 TTS 仍通过现有供应商适配层和私有媒体接口提供；没有可用凭据时，任务保持“音频准备中”，不能伪装为已就绪。
4. 孩子进入听写后，服务端只发送音频地址、拼音和语境。
5. 全部听完进入批改阶段后，才发送答案。
6. 暂停/继续属于当前浏览器的播放控制，不额外修改学习事实；完成播放、批改和复习记录仍沿用现有服务端状态机。

## 错误处理

- 拼音或语境缺失：种子验证失败，不允许应用该批数据。
- 官方词语缺失或会写字未覆盖：验证失败并输出具体缺项。
- 替换比例越界：验证失败并输出分子、分母和比例。
- 音频未准备好：沿用“音频正在准备”状态，不允许开始听写。
- 音频播放失败：保留现有重试提示，不能跳过并错误记录为已播放。
- 小节筛选结果为空：显示明确空状态，不保留不可见的已选卡片。

## 测试与验收

### 内容测试

- 两页词语表中的每个词语都存在于最终种子文件。
- 写字表中的每个会写字至少在一个最终词条中出现。
- 非词语表补充词的替换比例在 20%～40%。
- 所有语文词条都有拼音和仅含一个答案空位的原创语境。
- 所有 `broadcastText` 等于目标词语。
- 所有课次、语文园地和词序与核对结果一致。

### 服务测试

- 幂等导入不会创建重复教材、小节或卡片。
- 家长可按科目、单元和小节获得正确候选卡片。
- 听写阶段响应包含拼音和语境，不包含答案。
- 批改阶段按原流程返回答案。
- TTS 作业的输入只包含目标词语，不包含语境。

### 界面测试

- 科目切换会更新单元和小节选项并清理失效选择。
- 语文显示课次/语文园地，英语显示自身教材小节名称。
- 当前题显示拼音和语境。
- 点击语音块可以重复播放目标词。
- 连续模式可在播放中和题间等待时暂停并继续。
- 暂停、继续或重听不会提前显示答案。

## 实施顺序

1. 建立教材小节和卡片扩展字段的数据库迁移与类型。
2. 扩展种子结构、验证器和幂等导入命令。
3. 对照写字表、词语表和现有核对稿生成最终语文种子及审计报告。
4. 扩展家长筛选数据和“科目 → 单元 → 小节”界面。
5. 将拼音与语境安全投影到孩子听写阶段。
6. 补强语音重听、播放中暂停和题间暂停测试。
7. 运行单元、集成、类型、代码规范和构建验证。

## 完成标准

- 内容验证报告中：词语表缺失数为 0、写字表未覆盖数为 0、重复词数为 0、补充词替换比例为 20%～40%。
- 家长可以按科目、单元和教材小节筛选并创建任务。
- 孩子能看到拼音与语境，只听到目标词语，并能暂停、继续和重听。
- 听写阶段的网络响应不包含答案。
- 所有适用自动化测试、类型检查、代码规范检查和生产构建通过。
