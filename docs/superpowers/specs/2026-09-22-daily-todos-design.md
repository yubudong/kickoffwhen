# 今日待办、审核与积分

用户已在当前会话批准开始实现。

## 产品规则
- 家长导航“学习内容”改为“今日待办清单”；词库和录入整合进“今日听写”。
- 家长按孩子、日期逐条布置任务，字段为任务名称、任务要求。默认北京时间今天。
- 孩子清单列为“待办任务 / 任务要求 / 操作”。听写与普通任务在同一清单。
- 普通任务允许不上传或附一份图片、音频、视频后提交。首版文件上限 8MB，避免超过现有代理 10MB 请求限制；支持 JPG/PNG/WebP、MP3/WAV/M4A、MP4/WebM/MOV，校验真实文件头。
- 提交后保留任务并勾选、删除线，状态为“待审核”。通过显示“审核通过”；退回显示原因、取消完成状态，支持重新提交。
- 完成数量包括待审核与已通过；退回计入待完成。页面刷新和轮询更新审核状态。
- 听写布置自动创建待办；完成听写及订正后在同一事务中提交审核。退回听写允许附资料重新提交，保留原听写记录。
- 审核通过时发基础 1 分 + 非负整数奖励分（默认 0）。每任务唯一积分流水；审核和发分在一个事务中。显示总积分及本任务所得。
- 家庭/孩子隔离；只有家长可以布置审核；不因 URL 或请求参数允许越权。
- 附件仅本人和本家庭家长可读，使用受鉴权路由、禁止公网静态路径；图片、音视频可预览。
- 保留提交和审核历史。暂不实现重复周期、积分兑换、批量布置。

## 数据和兼容
独立 todo_tasks、todo_submissions、todo_reviews、todo_rewards 四表；听写关联 learning_tasks，唯一约束防重复。新任务创建/听写完成事务内写入待办；迁移补齐既有听写，原完成听写状态映射待审核，不追溯发分。附件使用 MEDIA_ROOT/todo，路径仅由服务生成 UUID，不接收路径输入。

## 验收
验证普通任务无附件/三类附件提交、待审核显示、退回再提交、通过立即到账、重复/并发审核不重复发分、跨孩子和跨家庭访问拒绝、听写自动进入清单及完成自动提交、旧记录兼容、移动端排版。
