# 英语纸笔与键盘听写

已确认范围：家长选择纸笔/键盘，键盘逐题听音输入、整轮提交、服务器核对，保留首次原始输入和订正，在线草稿恢复、规范变体家长复核；保留旧纸笔、中文、教材、复习与奖励。

## 决策

- learning_tasks.response_mode默认paper，旧任务无行为变化。keyboard只支持英语，内部采用continuous_batch与self标记，但UI为手动下一题、系统核对，不走纸笔自评API。
- 布置键盘任务时冻结每题答案、拼写规则、英语提示与认可变体，后续资料修改不更改任务判分。快照不在提交前返回给客户端。
- 草稿保存到按家庭/孩子/会话/轮次隔离的服务器记录，独立revision防止另一页面覆盖。不将原始输入存入localStorage/离线缓存。断网保留当前内存输入，联网后恢复保存，提交必须主动执行。
- 播放记录沿用现有按顺序/重听权限机制。键盘播放不进入纸笔grading；本轮全部题目听过且完整答案集合（允许显式空白）提交后，才生成不可变作答记录。
- 提交后展示自动结果；规范英美变体或不安全的未核对目标标pending，其他正常题按规则核对。不即时告诉输入正确与否，不由孩子传boolean成绩。
- pending复核后保留原自动结果与家长决策；孩子确认结果后，复用原首次/订正事务写reviewEvents、answerEvents和唯一completion事件。错词新轮清空输入并隐藏答案；首次错误不被后续答对覆盖。
- 结果页确认完成/进入错词订正为显式操作。首轮交卷后记录已保存，即使退出也可恢复结果；无pending时无需家长批改。任务原有奖励审核规则保持，不因键盘速度、重听或订正次数额外发奖。
- 家长复核页同时显示近期键盘报告，概览增加待复核入口。报告显示输入方式/标准或辅助、首次结果、原始输入、订正轮次和最终状态。

## 重点验证

禁止通过旧playback sequenceFinished/自评/照片/重开接口绕过键盘交卷；不同孩子/家庭不可读写；草稿版本冲突、丢响应重试、复核重试、重复完成与撤回并发；快照不泄露；首轮/订正FSRS语义与奖励防重；断网/刷新/切换、浏览器自动纠正关闭、手机和键盘快捷键；旧任务迁移所有旧列指纹保持。
