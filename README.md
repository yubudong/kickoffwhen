# KickoffWhen

2026 FIFA World Cup local kickoff time scheduler for Asia.

Live at [kickoffwhen.com](https://kickoffwhen.com).

## What it does

- Auto-detects your local timezone and shows every 2026 World Cup match in YOUR time
- Night-owl score — how worth it is to stay up for each match
- One-click add to calendar (Google / Apple)
- Favorite teams (no login required)
- Languages: Japanese, English

## Status

Pre-launch placeholder. Full site shipping before June 11, 2026.

## Tech

- Astro 4 (static site generation)
- Tailwind CSS
- Vanilla JS (no React)
- Cloudflare Pages
